Overview

This module is part of a private API. You should avoid using this module if possible, as it may be removed or be changed in the future.

A stable order for rows, so tapes come out the same on every Ruby version. Rows hold plain values only, see Adapters::Base#serialize, and the JSON format pins down how those are written. inspect does not, it changed in Ruby 3.4.
